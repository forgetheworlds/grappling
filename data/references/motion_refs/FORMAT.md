# Motion-reference dataset format — `data/references/motion_refs/v1/`

Version: **v1** (2026-10-08). Generated by `data/references/yt_gBAhX5t-GW4/derived/tools/retarget_video.py`
(the existing video→G1 retarget pipeline with the 2026-10-08 per-frame contact-aware
grounding fix), `scripts/compose_drill.py`, and the diagnosis scripts named below.
Everything is SI, radians, Z-up, 50 Hz (dt = 0.02 s), float64.

## Why v1 exists (the grounding defect it fixes)

`data/refs_video/*` (v0) floored the feet with ONE constant per take
(`place_solo`: min over 6 foot landmarks over the whole take). Measured in
`reports/2026-10-08/reference_fidelity.md` §4: emitted G1 soles hovered up to
**+0.111 m** or penetrated **−0.067 m**, posture-dependently. v1 replaces that
with two per-frame, contact-aware passes:

1. **Target level** (`ground_per_frame`): mediapipe landmarks are HIP-CENTRED,
   so a landmark's height above any take-level plane confounds "foot lifted"
   with "hips dropped" — a 0.30 m crouch raises every foot landmark by exactly
   the hip drop (the take-plane criterion lost 92 % of a level-change take's
   contact frames; the first fix attempt with a foot-speed gate was worse
   still, because hip-centred foot speed measures hip motion).  v1's PLANT
   criterion is therefore per-frame RELATIVE: a foot is planted when its sole
   is within 0.05 m of the LOWEST sole in the same frame (the stance foot),
   held for ≥0.13 s before (re)planting, and lifted once it exceeds 0.08 m
   above the frame's lowest sole.  The per-frame offset then shifts the whole
   frame so the lowest planted sole sits on the take's floor plane (5th
   percentile of pooled sole heights) — in the WORLD frame this exactly
   undoes the hip-centring artifact while preserving genuine step geometry
   (the clip is [−0.02, +0.60] m, wide enough for real crouches).  Frames with
   no planted foot interpolate (a real step/flight keeps body height
   continuous instead of inventing contact); a take with NO plantable frame
   falls back to the take-level constant, recorded in
   `meta.grounding.method`.
2. **Emitted-qpos level** (`ground_qpos_soles`): after solve+resample, FK the
   emitted trajectory and shift `qpos[:,2]` per frame by minus the lowest
   planted sole z (a root translation moves the whole robot rigidly, so this
   is exact; joint angles are untouched). Clip [−0.18, +0.15] m.

The pelvis translation is reconstructed with the PLANTED foot as anchor (the
old rule picked the smaller per-frame displacement and agreed with the video's
lower foot in only 26–77 % of clear frames): exactly-one-planted picks that
foot; both/neither keep the previous anchor; a switch needs the new foot
solely-planted for 0.20 s.

Measured result on `stance_hold` (smoke test, 2026-10-08): emitted sole
median **0.0000 m** (was +0.0334 m), min −0.003 m (was −0.067 m on the worst
take), time stretch 1.000, weighted landmark RMS 0.051 m.

## Individual take references — `refs/<name>.npz`

Same npz family as `data/refs_video/*` (loaded by `src/solo/bc.py:load_reference`
→ `ReferenceTrack`), plus the new v1 keys:

| key | shape/dtype | meaning |
|---|---|---|
| `qpos_a` | (T,36) f8 | free joint (7) + 29 joints, 50 Hz, model order — the DESIRED reference trajectory |
| `qpos_b` | (T,36) f8 | zeros (single-robot retarget; the two-robot solver's slot B is meaningless here) |
| `t` | (T,) f8 | seconds from take start |
| `technique` | str | take name |
| `edges` | (0,) i8 | empty (video-sourced, not a GrappleMap chain) |
| `landmark_rms` | f8 | weighted site RMS of the emitted trajectory vs targets |
| `contact` | (T,2) u8 | **v1**: planted flags (left, right) per frame, from the contact detector above |
| `meta` | JSON str | provenance + diagnostics, see below |

`meta` fields: `source_npz`, `source_window_s`, `source_frames`,
`source_fps_effective`, `gap_frames`, `gap_frac`, `scale_g1_over_human`,
`facing_deg_in_mp_frame`, `floor_offset_m` (median per-frame shift),
`grounding` = {method, floor_plane_m, contact_frac, offset_med/max_m,
qpos: {method, shift_min/med/max_m, other_planted_sole_max_m,
contact_frac_50hz}}, `anchor_right_frac` (fraction of frames the RIGHT foot was
the translation anchor), `net_travel_m`, `preset`, `keyframes`,
`time_stretch_kinematic`, `duration_s`, `dt`, `rms`, `ambiguities` (monocular
depth, LSQ scale, static camera, GM proxy joints), `source`, and — added by the
diagnosis pass — `lead_leg` (`"left"` or `"right"`: the video's lead/forward
foot at the take's end posture), `validity` (see categories), and
`validity_reason`.

**A reference is a kinematic TARGET trajectory, never an executed
demonstration.** `qpos_a` frames are desired poses for a tracking policy; they
carry no claim of dynamic stability and MUST NOT be used as `expert_action`.

## Composed references — `drill_continuous.npz`, `stance_to_stand.npz`

Built by `scripts/compose_drill.py` from the take references above:

| key | shape/dtype | meaning |
|---|---|---|
| all take keys | | as above (`qpos_a` is the continuous 50 Hz drill trajectory) |
| `phase_id` | (T,) i8 | phase index per frame, into `meta["phases"]` |
| `contact` | (T,2) u8 | per-frame planted flags (merged from takes + connector synthesis) |

`meta["phases"]` is an ordered list of
`{id, name, t_start, t_end, source, lead_leg, validity, validity_reason, note}`
where `source` ∈
* `"observed"` — retargeted video take (motion as filmed, grounded),
* `"g1_native"` — G1 keyframe from `src/solo/stance.py` (stand/stance anchors),
* `"synthetic_connector"` — minimum-jerk blend manufactured by composition
  (never observed motion; also flagged in `note`),
* `"fused"` — video timing + GrappleMap spatial constraints (see
  `fusion_spec.json`).

`meta["composition"]` records the blend windows, world-offset chain (root
displacement accumulates), and boundary-continuity metrics.

## Validity categories (three-level feasibility diagnosis)

Every phase/segment carries `validity` ∈
* `"kinematically_valid"` — joint positions inside limits, bounded velocities,
  no self/ground penetration in FK (level 1),
* `"statically_holdable"` — additionally: the held posture keeps the CoM inside
  the support hull with ≥0 margin in MuJoCo FK, and the posture is one the
  certified stance controller can hold (level 2; measured by
  `scripts/feasibility_diagnosis.py`),
* `"dynamically_verified"` — additionally: a real MuJoCo rollout driving the
  segment's targets with the standard 50 Hz position-servo interface stays
  upright through the segment (level 3; `scripts/probe_drill_dynamic.py`;
  success AND failure are reported, never inferred from kinematics),
* `"unverified"` — kinematically valid but no static/dynamic evidence yet,
* `"known_infeasible"` — a specific measured reason is recorded
  (e.g. the shot-entry pre-step crouch: statically balanced but dynamically
  topples in 1.24 s — `reports/2026-10-08/cem_capture.md`).

## Loading (the command Agent 2 can run)

```
.venv/bin/python scripts/query_motion_refs.py            # table of all tracks
.venv/bin/python scripts/query_motion_refs.py drill_continuous --phase
```

```python
from solo.bc import load_reference
tr = load_reference("drill_continuous")   # ReferenceTrack(qpos, t, meta)
```
`load_reference` resolves `data/references/motion_refs/v1/refs` +
`data/references/motion_refs/v1` (registered in `src/solo/imitation.py:REFERENCE_DIRS`)
alongside the legacy `data/refs_video` and `data/refs` directories.
